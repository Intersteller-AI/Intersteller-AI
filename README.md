## 🚀 Featured Projects

### 🤖 CoolCare — Autonomous WhatsApp AI Agent

An autonomous WhatsApp AI agent for AC service businesses that handles the
complete service workflow — from customer booking to dispatch, technician
routing, and payment.

**What makes it interesting**

- Fully autonomous service workflow with **zero human intervention**
- **5-actor architecture:** Customer → AI Agent → Business Owner → Technician → Payment
- **7-stage Redis-backed state machine** for conversation and execution state
- Maintains workflow state across Meta's **24-hour WhatsApp session window**
- Semantic RAG using `text-embedding-004` for automated FAQ resolution
- Razorpay auto-invoicing triggered on job completion
- WhatsApp interactive menus for business-owner and technician actions

**Stack**

`LangChain` `Gemini 2.0 Flash` `FastAPI` `GCP Cloud Run`
`MongoDB Atlas` `Redis` `Razorpay` `WhatsApp Cloud API` `Next.js`
